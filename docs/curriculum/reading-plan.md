# 《加密与解密》（第4版）阅读计划

已确认：路线 0→10；**主教材 = 段钢《加密与解密》第4版**（电子工业出版社）。  
工具以书中概念为准，软件用现在的：**动态以 x64dbg 为主**（书 2.2），OllyDbg 只建立「断点/内存/栈」直觉；**静态以 Ghidra 对照 IDA 章节**（书 3.3 的 xref、重命名、函数、结构体，换到 Ghidra 做一遍）。

本书几乎不讲 ELF / ARM / 固件 / 流量。那些阶段用标注的**中文补读**，不改主教材。

## 有基础但不系统：前四周怎么改

默认周计划按「第1章当入门」写。你若已会一点 C/汇编/Win32，改走 **查漏补图**：

| 天 | 做什么 |
|----|--------|
| 1 | 搭环境；按 [阶段 0 自测清单](phase-00-foundation.md) 标绿/黄/红 |
| 2 | 第1章 **速读**（不抄书）；只精读标红的 1.2、1.3 |
| 3–6 | **通读第4章**（4.1 再 4.2）。黄/红项在 Ghidra 对着自己的 `.c` 指一遍 |
| 7 | 写出 `methods/foundation-map.md`，红项必须有「书中小节 + 自己的例子」 |

然后从原周计划 **第5周（第2章 x64dbg）** 接上。第1章不必单独花一整周。

未测先标黄，不允许凭印象全标绿。
