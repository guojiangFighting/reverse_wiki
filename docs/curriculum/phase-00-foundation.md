# 阶段 0：C、汇编、操作系统

> **若你已有基础但不系统**：不要把第1章当零基础重读。先做下面「查漏补图」，再只精读标红的缺口。第4章仍建议通读——它是把零散直觉收成体系的那一章。

## 有基础时怎么学（推荐）

目标不是「再上一次入门课」，而是交出一张 **能用自己的话讲完、能在工具里指出来** 的知识图。

1. **先测后读（1～2 天）**  
   对下表每一项：能讲清 + 能在 Ghidra/调试器里指出来 = 绿；只能讲不能指 = 黄；讲不清 = 红。只精读红/黄对应的书节。
2. **用第4章当骨架，不用第1章当主课**  
   第1章快速扫（API、消息、虚拟内存），缺哪补哪。第4章 4.1→4.2 必须过一遍，这是把 C、栈、调用约定、控制流收拢的地方。
3. **产出是一张图，不是读书笔记抄写**  
   蒸馏页 `methods/foundation-map.md`：进程/内存、栈帧、调用约定、C↔汇对照。绿项一句话，红项写「看了书哪一节 + 自己的例子」。
4. **压缩时间**  
   零基础周计划里阶段 0 要 3～4 周；有基础应 **7～10 天内完成查漏 + 第4章**，然后进入第2、3章工具。

### 自测清单（绿/黄/红）

| 项 | 「绿」长什么样 |
|----|----------------|
| 虚拟地址 vs 文件偏移 | 能说明 PE 里 RVA/RAW 差别（细节可留到第11章） |
| 栈帧 | 能画 call 前后 rsp/rbp（或省略帧指针时）谁保存返回地址 |
| 调用约定 | 能说出 x64 Win 前四个参数在哪；Linux SysV 在哪（可只精一门，另一门标黄） |
| C 的 if/for/switch | 能在反编译窗口指回源码结构 |
| 指针与数组 | 能解释 `[rax+rcx*4]` 一类寻址 |
| 全局 vs 局部 vs 堆 | 能说明三种对象大概在哪类节/谁分配 |
| 调用约定破坏 | 能解释为何 stdcall 清栈错了会炸 |

自测方法：写一个小 C 文件（参数≥4、有循环、有结构体指针），`-O0` 编译，Ghidra 打开，对着表口述。卡壳的项标红，去第4章对应小节。
