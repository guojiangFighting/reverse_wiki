# 阶段 0：基础

已有基础：先做实操里的自测程序，清单能勾的直接勾，不要重学入门课。

## 知识点

- 虚拟地址与文件偏移（RVA 细节可留到阶段 2）
- 栈：返回地址、局部变量、call 前后
- 调用约定：x64 Windows 前四参数；Linux SysV 可标黄后补
- if / for / switch 在汇编/反编译里的形状
- `[base+index*scale]`、指针与数组
- 全局 / 局部 / 堆 大概在哪

## 实操

1. 写一个 C：`int foo(int a,int b,int c,int d, struct S *p)`，内含循环和 `p->field`。`-O0` 编 64 位。
2. Ghidra 打开，边看边对着知识点口述。
3. 可选：同一源码再编 32 位对比传参。
4. Godbolt 只用来快速对照，不能替代「本地文件进 Ghidra」。

卡壳再查《加密与解密》第4章对应小节。
