# 学习路线

原则：**知识点清单 → 实操 → 掌握确认（能讲 + 能指）**。  
已有基础：先自测，绿项跳过，黄/红才补。书只在卡壳时当字典，不作为主路径。

**已确认**

- 顺序仍是下面 10 段（2 与 3 可并行；4 在 7 前；6 在死磕家族前）
- 过关不以「读完某书」为准，而以本页/各阶段勾选为准
- 《加密与解密》第4版改为 [可选查阅](reading-plan.md)

```text
0 基础 → 1 工具 → 2 PE / 3 ELF → 4 ARM
 → 5 加壳与算法 → 6 恶意软件通论
 → 7 固件与 IoT → 8 托管与文档 → 9 流量 → 10 沉淀
```

| 阶段 | 掌握了就是 | 未掌握就是 |
|------|------------|------------|
| 0 | 对着自己的二进制讲清栈、传参、控制流 | 只能背名词 |
| 1 | Ghidra 找到函数并改名；调试器下到比较点 | 不会导入/不会下断 |
| 2 | 画出 PE 节区与导入，判断入口是否像原程序 | 只会看 DIE 结论 |
| 3 | strip 前后仍能找回校验逻辑 | 没有符号就不会看 |
| 4 | 选对 ARM 架构并指出参数寄存器 | 反编译像乱码还不觉得架构错了 |
| 5 | 用节区/熵/导入判断 packed；认出 XOR/哈希常量 | 只会说「好像加壳了」 |
| 6 | 能按能力给样本分类并写出分析顺序 | 直接按家族名搜 writeup |
| 7 | 官方固件解出 rootfs 并指出一个服务入口 | 只会 binwalk 截图 |
| 8 | 见到 .NET/APK/宏会换对应工具 | 当原生 PE 硬啃 |
| 9 | 从 pcap 列出侧写字段 | 只会「有一堆包」 |
| 10 | 手法页别人能照着做 | 只有 lab-log 情绪记录 |

每阶段结构相同：知识点（须能口述）→ 实操 → 掌握确认（全勾才进入下一阶段；绿项可直接勾）。
